# Contributing

Terima kasih ingin berkontribusi pada Embedded Git Lab.

## Prinsip

- Utamakan nilai pembelajaran, bukan sekadar menambah command.
- Setiap mission harus memiliki kondisi awal, target, success condition, dan feedback.
- Simulator tidak boleh menjalankan shell atau Git asli pengguna.
- Perubahan simulator harus memiliki test.
- Gunakan Bahasa Indonesia untuk materi belajar dan UI; command Git/GitHub CLI tetap mengikuti sintaks asli.

## Workflow

1. Buat issue atau pilih issue yang ada.
2. Buat branch yang deskriptif, misalnya `feat/mission-git-stash`.
3. Tambahkan perubahan dan test.
4. Jalankan `npm test` dan `npm run build`.
5. Buat Pull Request dengan penjelasan perubahan.
