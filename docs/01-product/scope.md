# Scope — v1.0.0

## In scope
- Web app single-player berbahasa Indonesia.
- React + TypeScript + Vite + Tailwind.
- 5 level, 25 misi tutorial/challenge.
- Simulator Git/GitHub CLI client-side.
- Terminal, objective panel, branch/repository state, virtual files.
- XP, hint, achievement ringan.
- Autosave, resume otomatis, checkpoint, reset mission.
- Local persistence via `localStorage`.
- Static deployment ke GitHub Pages.
- Automated unit tests dan CI.

## Level
1. Git Fundamentals.
2. Branch & Remote Workflow.
3. Recovery & Troubleshooting.
4. GitHub Collaboration.
5. Embedded Release Workflow.

## Out of scope
- Backend, akun, login/OAuth nyata, cloud save.
- Multiplayer, leaderboard online, classroom dashboard.
- GitHub API nyata atau perubahan repository pengguna.
- Shell/Git executable nyata, compiler firmware, atau simulator hardware.
- Full IDE/editor.

## Target device
Desktop/laptop utama; tablet terbatas. Mobile tetap dapat membuka aplikasi tetapi bukan target UX utama.

## Definition of Done
v1 dianggap release candidate ketika lint, typecheck, automated test, dan production build lulus; seluruh 25 misi dapat dimuat; state persistence bekerja; dan GitHub Pages workflow tersedia.
