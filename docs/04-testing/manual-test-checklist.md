# Manual Test Checklist

- [ ] Landing langsung memuat misi aktif.
- [ ] Semua level dapat dipilih.
- [ ] Semua 25 misi dapat dibuka.
- [ ] Terminal menerima command dan output dapat discroll.
- [ ] `help` menampilkan keluarga command.
- [ ] Objective berubah setelah state terpenuhi.
- [ ] Checkpoint dibuat saat objective baru tercapai.
- [ ] Hint bertambah satu per klik.
- [ ] XP tidak diberikan dua kali untuk misi yang sama.
- [ ] Reload mempertahankan progress.
- [ ] Reset misi tidak menghapus completion global.
- [ ] Hapus save mengembalikan default.
- [ ] Repo tab dan Files tab mencerminkan state.
- [ ] Mobile tidak overflow fatal; desktop layout terbaca.
