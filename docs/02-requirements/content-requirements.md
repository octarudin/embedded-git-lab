# Content Requirements

- Bahasa penjelasan: Indonesia; command tetap sintaks asli Git/GitHub CLI.
- Skenario memakai konteks firmware/embedded yang konsisten.
- Materi membedakan fakta Git dengan best practice; naming branch tidak diperlakukan sebagai satu standar universal.
- Operasi destruktif dijelaskan sebagai konteks khusus, bukan default solution.
- Binary build tidak dianggap otomatis layak di-commit; release asset dipisahkan dari source history.
- Secret/credential tidak boleh diajarkan untuk di-commit.
