# Mission Catalog

> Status: Draft seed.

## Kandidat Kasus

- Inisialisasi Git pada folder kosong.
- Inisialisasi Git pada source code yang sudah ada.
- `.gitignore` untuk project embedded.
- Fetch/pull/update terbaru dari remote.
- Best practice branch naming.
- Pembuatan branch lokal dan feature development.
- Commit dan push branch lokal.
- Merge lokal dan merge ke `main`.
- Salah branch, salah stage, salah commit.
- Tag lokal/remote dan release.
- Sinkronisasi branch remote yang lebih baru.
- Memindahkan tag dari commit-1 ke commit-2 dan memperbarui release.
- Menambahkan binary file ke release.
- Clone, remote URL, upstream, stash, conflict, cherry-pick, prune, detached HEAD.
- GitHub issue/PR/review/merge.
- Submodule, firmware artifact, checksum, semantic versioning.
