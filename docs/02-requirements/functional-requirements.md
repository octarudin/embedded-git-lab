# Functional Requirements

- **FR-01** Aplikasi memuat learning path 5 level dan 25 misi.
- **FR-02** Pengguna dapat memilih misi dari sidebar.
- **FR-03** Terminal menerima input command dan menampilkan output simulasi.
- **FR-04** Simulator mengubah repository state untuk command yang didukung.
- **FR-05** Objective dievaluasi setelah setiap command.
- **FR-06** Checkpoint dibuat ketika objective baru tercapai.
- **FR-07** Pengguna dapat membuka hint bertahap.
- **FR-08** Reward XP diberikan satu kali per misi.
- **FR-09** Progress dan session tersimpan otomatis.
- **FR-10** Pengguna dapat restore checkpoint dan reset misi.
- **FR-11** UI menampilkan branch, HEAD, upstream, tags, PR, release, dan virtual files.
- **FR-12** Simulator mendukung subset Git: init, status, branch, switch/checkout, add, restore, commit/amend, log, diff, remote, fetch, pull, push, merge, stash, tag, reset, revert, cherry-pick.
- **FR-13** Simulator mendukung subset GitHub CLI: auth, repo create, issue create, pr create/status/merge/close, release create/upload/delete.
- **FR-14** Release asset dapat berupa binary virtual seperti `build/firmware.bin`.
