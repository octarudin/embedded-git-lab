# Game Requirements

## Loop
Briefing → observasi → command → output → state berubah → objective tervalidasi → checkpoint → reward.

## XP
Setiap misi memiliki base XP. Setiap hint yang dibuka mengurangi 15 XP; reward minimum 30 XP.

## Hint
Setiap misi memiliki minimal tiga level hint: konseptual, arah command, dan petunjuk lebih eksplisit.

## Achievement v1
- `zero-hint`: menyelesaikan setidaknya satu misi tanpa hint.
- `release-engineer`: menyelesaikan seluruh katalog misi.

## Challenge
Misi challenge memberikan briefing lebih ringkas dan mengharuskan pemain menentukan urutan command sendiri.
