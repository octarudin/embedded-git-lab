# UI/UX Design

## Visual direction
**Modern learning app + embedded engineering workstation.** Dark theme, monospace untuk terminal/state, aksen emerald/cyan/amber, tanpa gaya hacker berlebihan.

## Desktop layout
- Kiri: learning path dan mission selector.
- Tengah: briefing, terminal, completion panel.
- Kanan: tabs Mission / Repo / Files + recovery controls.

## Interaction
- Terminal keyboard-first dengan tombol Jalankan sebagai alternatif.
- Status objective memakai ikon + teks, bukan warna saja.
- Hint progressive disclosure.
- Autosave indicator selalu terlihat.

## Responsive behavior
Grid tiga kolom aktif pada layar lebar. Pada layar lebih kecil, panel menjadi vertikal; terminal tetap prioritas utama.
